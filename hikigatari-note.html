出力するもの

出力しないもの

リスナー一覧・リクエスト主・自由記述メモ・URL・正確な日時・内部ID。 曲名とアーティスト名が両方ない記録は、未特定件数としてだけ扱います。

曲名やアーティスト名に個人情報を書いた場合は、その内容が残ります。 匿名性を保証するものではありません。 AIへ渡す前に内容とサービス側の保存・学習・共有設定を確認してください。

    コンパクト表示・登録フォーム
    

      一覧はアーティスト名・曲名を優先します。
      「操作・詳細」を開くと、編集・履歴追加・削除・説明などを表示します。
      小さい画面ではタブを横スクロールしてください。
      文字やボタンは画面幅に合わせて調整します。
    

    

      「＋ 新規登録」で登録フォームを開きます。
      「編集」でも開き、保存後は畳みます。
      「入力を閉じる」は入力を残して畳みます。
      変更中の入力がある場合は「入力を再開」できます。
      新規入力への切り替えやリセット時は確認します。
      未保存の入力は、ページ再読み込みで失われます。
    

    

      アーティスト・リスナーの追加フォームも折り畳み式です。
      ブラウザ側の文字拡大機能も利用できます。
    

  


  

    履歴・ランキング・レパートリー
    

      履歴１件を１回の歌唱記録として集計します。
      曲を開くだけでは履歴は増えません。
      「歌った」は押すたびに１件追加します。
      完唱・成功を自動判定するものではありません。
    

    

      リクエストの「演奏済み→履歴」は、１リクエストにつき１回だけ追加します。
      その履歴を削除してもリクエストの演奏済み状態は自動解除しません。
      再演は履歴などの「もう一度歌った」から追加できます。
    

    

      レパートリー登録・習熟度変更では履歴は増えません。
      習熟度は自己評価です。
      歌唱回数から習得度や好みを自動判定しません。
    

    

      アーティスト名と曲名がそろう記録は、
      文字幅・空白・英字大小を軽く正規化して同曲集計します。
      同名の別アレンジは同曲集計ですが、音楽情報は複数候補として扱います。
      表記ゆれは必要に応じて編集してください。
    

    

      名前未設定の記録はURLで照合します。
      同URLに名前付き記録が１種類だけある場合は合算します。
      名前もURLもない記録は個別扱いです。
    

  


  

    固定名保存・上書き保存
    

      通常バックアップ名は ufret_backup.json です。
      AI分析用.mdは区別のため日時付きです。
      通常バックアップの上書きと、ブラウザ内保存は別の処理です。
    

    

      対応環境では初回に保存先を選びます。
      既存JSONの保存日時を確認してから上書きします。
      savedAtがない場合はファイル更新日時を表示します。
      保存先はこのタブを開いている間だけ覚えます。
      再読み込み後は、既存のファイルをもう一度選んでください。
    

    

      対応APIがあっても、権限・ブラウザ設定・実行環境で利用できない場合があります。
      その場合は「固定名でダウンロード」を使ってください。
      保存先選択で新規の空ファイルが作られた場合、
      その後キャンセルしても空ファイルが残る可能性があります。
    

    

      通常ダウンロードでは、既存ファイルの場所・日時・保存完了を確認できません。
      表示される前回日時はダウンロード操作日時です。
      スマホなどでは(1)が付いた別名になる場合があります。
      実際の上書きは端末の保存画面やファイル管理で行ってください。
    

    

      上書きすると、そのファイルの以前の内容に戻せません。
      大きな変更や削除、移行の前は別の場所にもコピーを残してください。
      他アプリとの完全な排他制御や、端末障害時の保存を保証するものではありません。
    

  


  

    AI分析の使い方・限界
    
    
      
  1. 「AI分析」を開きます。
    2. 
      
  2. 必要なら自己申告音域を保存します。
    3. 
      
  3. 分析用出力を生成します。
    4. 
      
  4. 内容を確認してチェックを付けます。
    5. 
      
  5. .mdを保存するか、全文をコピーしてAIへ渡します。
    6. 
    

    

      分析用出力は実行プログラムではなく、依頼文と集計JSONです。
      通常バックアップとは別物で、復元には使えません。
      自動送信・自動同期はありません。
    

    

      キーだけから旋律音域や声種は分かりません。
      曲の音域が分かっても本人が安定して出せる証明にはなりません。
      録音なしでは、声質・発声・音程精度を判定できません。
      AIには事実・仮説・不足情報を分けるよう依頼します。
    

    

      未演奏・未記録は、嫌い・苦手・未習得とは限りません。
      リクエスト件数は人数ではありません。
      原曲と自分のアレンジの違いにも注意してください。
    

    

      痛み・かすれ・強い疲労がある場合は無理に歌わないでください。
      続く場合は医療機関に相談してください。
      AI分析は医学的診断や専門家による歌唱評価ではありません。
    

  


  

    旧版変換・追加統合
    

      artists・history・favorites・requestsの旧形式、
      songs＋songId形式、前回の1.0.0・1.1.0形式に対応します。
      未知の独自形式には対応できない場合があります。
      不正URLや参照先不明の曲は黙って削除せず、読み込みを停止します。
    

    

      ID不足は補完し、URLなしリクエストも残します。
      元データにない歌唱日時は復元せず、日時不明にします。
      新しい音楽情報がない場合は未記録です。
      元のJSONを変更しません。
      未知の追加項目は引き継がないため原本を保管してください。
    

    

      追加・統合はIDを基本に照合します。
      お気に入り・レパートリーは名前とURLが両方同じ重複を整理します。
      IDなし旧データを編集して再出力した場合は、別記録になることがあります。
      削除の同期はしません。
      完全に同じ内容にする場合は上書きを選択してください。
    

  


  

    データの保存場所・別端末での利用
    

      HTML本体に記録を書き込むわけではありません。
      ブラウザ内のlocalStorageに保存します。
      保存キーは1.1.0との互換性を保つため ufret_note_1_1_0 を使用します。
    

    

      HTML直接表示の保存動作はブラウザ依存です。
      ファイル名・場所・ブラウザを変えると保存内容が見えない場合があります。
      一部のファイルプレビューではJavaScriptが動きません。
      一時利用モードでは、閉じる前にJSONを保存してください。
    

    

      通常ダウンロードの保存先は端末・ブラウザ設定によります。
      一般には「ダウンロード」です。
      iPhoneでは「ファイル」のiCloud Driveまたは
      「このiPhone内」のダウンロードを確認してください。
      このアプリから保存先の完全なパスを取得することはできません。
    

    

      別端末にはHTMLと通常バックアップJSONを移し、
      新端末でJSONを読み込みます。自動同期はありません。
      コピー機能はファイルの場所ではなく内容全文をコピーします。
    

  


  

    セキュリティ・PHPについて
    

      このHTMLはPHPを実行せず、PHP実行環境も必要としません。
      PHP実行環境を攻撃する脆弱性について、
      このアプリ内に対象となるPHP処理はありません。
      song.phpなどはリンク先サイトのURLです。
    

    

      リンク先や、HTMLを設置するWebサーバーの安全性は別問題です。
      PHPを使わないことは完全な安全性の保証ではありません。
      この説明は特定の最新CVEに対する包括的な監査結果ではありません。
    

    
    
      
  • 外部JavaScript・広告・解析サービスは読み込みません。
    • 
      
  • バックアップや分析データの自動送信はしません。
    • 
      
  • JSON.parseで読み、文字列をコードとして実行しません。
    • 
      
  • 登録文字列はtextContentで表示します。
    • 
      
  • 登録リンクはhttpsのufret.jp／www.ufret.jpに限定します。
    • 
      
  • 別タブにnoopener・noreferrerを指定します。
    • 
      
  • 読込上限10MiB、各配列30,000件です。
    • 
      
  • 保存データ・JSON・分析用.mdは暗号化していません。
    • 
    

    

      OS・ブラウザを更新し、信頼できるHTMLを使用してください。
      パスワードなどは記録しないでください。
      通常バックアップにはリスナー情報が含まれます。
      AIへ送った情報の取り扱いは、利用するサービスの規約・設定に従います。
